# Megaline Plan Classification

Machine-learning classification of mobile plans from subscriber usage data.

[View the notebook](notebook.ipynb)

## Work demonstrated

- Exploratory analysis of calls, minutes, messages, and data usage.
- Train/validation/test splitting and comparison of classification models.
- Hyperparameter selection, held-out evaluation, and interpretation of feature importance.

This is the Sprint 8 machine-learning project, separate from [Megaline statistical analysis](https://github.com/devinkristopher/megaline-sda).

## Running and provenance

The notebook preserves saved results from the recovered coursework. Reviewer commentary was removed; computational code and its saved outputs were retained. It has not been rerun for publication. Full datasets are not redistributed here; obtain the course dataset separately and adjust its path before running. Dependency lists below are inferred from imports, not a locked reproduction environment.

Open `notebook.ipynb` in Jupyter after installing the dependencies in `requirements.txt`.
